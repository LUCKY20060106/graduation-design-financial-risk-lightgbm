创新点（建议控制在3项）
创新点1
针对类别不平衡问题，引入 Adaptive SMOTE + 类别权重 优化 LightGBM 对少数类 ST 企业
的识别能力。
创新点2
结合 Variance Threshold 进行特征筛选，降低冗余特征对模型训练效率和预测性能的影响。
创新点3
设计并实现 SpringBoot + Vue + Python 模型服务 的 B/S 财务风险预警系统，实现数据管
理、模型预测、结果可视化和报表导出的一体化流程。
建议避免宣称"提出新的LightGBM算法"，因为你的工作属于基于已有算法的改进与工程
实现，这对于本科毕设是完全合理且容易自圆其说的。

一定要注意的事项（非常重要）
 分区 计算机毕设 的第 7 页 
一定要注意的事项（非常重要）
1. 不要过度堆砌算法
建议控制为：
Variance Threshold → Adaptive SMOTE → LightGBM（Class Weight）→ SHAP
这条主线已经足够完整。
2. 数据处理流程必须正确
一定注意顺序，例如：
数据划分 → 在训练集上进行特征筛选和SMOTE → 训练模型 → 将同样的特征处理应用
到测试集 → 测试模型
避免测试集信息泄漏到训练过程中。
3. 保证实验可复现
记录：
• 数据来源 
• 数据时间范围 
• 特征列表 
• 随机种子（如使用） 
• LightGBM主要参数 
让别人能够重复实验。
4. 原理要能讲，不要只会调用库
老师往往不会问你API，而会问：
为什么这样设计？
因此，论文和答辩都应围绕原理、设计理由和实验验证展开，而不是停留在代码调用层面。
